# Sproutfy
Sproutfy is an Arduino Mega2560-powered smart irrigation system that monitors soil moisture and climate conditions in real-time. It automatically controls water pumps based on sensor data, shown on an OLED display. Designed for precision and efficiency, it optimizes water usage for sustainable plant care.

### Components used:
* 1 Mega Wifi R3 Atmega2560 Board with ESP8266 and CH340
* 1 4 Channel 5v Relay Module
* 4 Mini DC 3V-5V Water Pumps
* 4 Capacitive Soil Moisture Sensor
* 1 0.96-inch 128x64 Yellow Blue OLED Module SSD1306 OLED 128x64 (SSD1306)
* 1 Real Time Rtc Ds3231 Module
* 1 Barometric Pressure Humidity and Temperature Sensor Module (BME280)
* Protoboards, wires, 12v font
